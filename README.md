# how to build

package-lock already has `gh-pages` (ran ```npm install gh-pages --save-dev```) so just do:
``` 
npm install 
``` 
(like you had any choiceಥ_ಥ)
\
\
\
you could run with
```
npm run dev
```
or you could build with
```
npm run build
```
\
\
\
but if you want to deploy, you've got to build it for gh-pages. first it would be
```
npm run predeploy
```

and then
```
npm run deploy
```
\
\
\
thats all
